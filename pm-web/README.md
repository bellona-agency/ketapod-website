# تخته کارها — فرانت

ابزار داخلی مدیریت پروژه تیم، شبیه جیرا. Next.js 16 (App Router) روی
Tailwind v4، در برابر API جدای `backend/cmd/pmapi` (پورت ۸۰۹۰، schema
جدای `pm`، هویت مستقل از حساب کاربری سایت).

```bash
npm install
npm run dev        # روی ۳۰۰۱
```

`NEXT_PUBLIC_PM_API_BASE_URL` را در `.env.local` بگذار (پیش‌فرض
`http://localhost:8090`). در باندل کلاینت بیک می‌شود، پس عوض‌کردنش build
دوباره می‌خواهد نه restart.

## نقشه کد

```
src/
  app/
    login/                ورود، و ساختن اولین حساب اگر هنوز عضوی نیست
    invite/[token]/       پذیرش دعوت
    (app)/                هرچه نشست می‌خواهد — AppShell دورش است
      page.tsx            «کارهای من»
      projects/           فهرست و ساخت پروژه
      p/[key]/            برد، بک‌لاگ، ایشیوها، گزارش‌ها، تنظیمات
      issue/[key]/        صفحه ایشیو
      timesheet/          زمان ثبت‌شده خودم
      members/            اعضای تیم (فقط مدیر)
      me/                 پروفایل و تغییر رمز
  components/             AppShell، کارت و ردیف ایشیو، کامپوزر، فیلترها،
                          زنگ اعلان، نمودارها، منشن‌باکس، پریمیتیوها
  lib/
    api.ts                fetch + refresh تک‌مسیره
    auth.tsx              نشست و هدایت
    project.tsx           پروژه، ستون‌ها، برچسب‌ها، اعضا و اسپرینت‌ها
    hooks.ts              useResource و شمارنده اعلان روی SSE
    format.ts             تاریخ و عدد فارسی، برچسب‌ها
```

## تصمیم‌های فرانت

**زبان رنگی از دیزاین‌سیستم سایت می‌آید، هندسه‌اش نه.** آن دیزاین‌سیستم
برای لندینگ محصول است: شعاع ۲۰ پیکسل، دکمه‌های قرص، تراکم ۳. اینجا
ابزاری است که آدم هشت ساعت در روز نگاهش می‌کند و باید صد کارت را در یک
صفحه جا بدهد. یک پالت، دو هندسه.

**درگ‌ودراپ بدون کتابخانه.** برد چند مقصد رها کردن است و یک عنصر کشیده‌شده؛
کتابخانه‌هایی که این کار را خوب می‌کنند برای درخت‌های مرتب‌شونده و
گریدهای مجازی‌اند و آوردن یکی‌شان از کل این صفحه بیشتر کد به مرورگر
می‌فرستاد.

**نمودارها SVG دست‌ساز.** دو نمودار ساده در برابر کتابخانه‌ای که روی
صفحه‌ای که هر اسپرینت یک بار باز می‌شود شصت کیلوبایت خرج می‌کند.

**بدون SWR و React Query.** چند صفحه، هرکدام یکی دو منبع، و هر تغییری
خودش می‌داند چه چیزی را باطل کرده. `reload` صریح صدا زده می‌شود.

**SSE با fetch، نه EventSource.** `EventSource` نمی‌تواند هدر
`Authorization` بگذارد و راه‌حل رایج — گذاشتن توکن در query string —
توکن را در لاگ هر پراکسی و تاریخچه مرورگر می‌نویسد. اگر استریم به هر
دلیلی نگیرد، هوک خودش به polling برمی‌گردد.

**فونت وزیرمتن، خودمیزبان.** تنها فونت فارسی باکیفیت با مجوز تجاری امن
(`SIL OFL`) — برخلاف فونت‌هایی مثل دانا که مجوزشان تجاری نیست. دو
زیرمجموعه (عربی و لاتین) در `src/fonts/` هستند تا build به شبکه وابسته
نباشد.

**اعداد فارسی همه‌جا، جز دو استثنا.** کلید ایشیو (`KET-142`) و مدت
زمانی که در فیلد تایپ می‌شود لاتین می‌مانند: کلیدی با اعداد فارسی را
نمی‌شود در نام برنچ چسباند و مدتی با اعداد فارسی را نمی‌شود دوباره در
فرم گذاشت.
